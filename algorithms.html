Algorithms

Algorithms for the DSA lab programs

  1. Matrix Addition

    1. Start
    2. Read the number of rows and columns of the matrices
    3. Read all elements of the first matrix
    4. Read all elements of the second matrix
    5. For each row i and column j
      1. result[i][j] = A[i][j] + B[i][j]
    6. Display the result matrix
    7. Stop

  2. Polynomial Addition

    1. Start
    2. Read the number of terms in polynomial 1 and polynomial 2
    3. Read each term as (coeff, exponent) for both polynomials
    4. Initialize pointers i, j, and k to the first term of each polynomial and result
    5. while (i < n1 and j < n2)
      1. if (A[i].exp == B[j].exp) then
        1. SUM[k] = (A[i].coeff + B[j].coeff, A[i].exp)
        2. i++, j++, k++
      2. else if (A[i].exp > B[j].exp) then
        1. SUM[k] = A[i]
        2. i++, k++
      3. else
        1. SUM[k] = B[j]
        2. j++, k++
      4. endif
    6. Copy the remaining terms of the first polynomial to the result
    7. Copy the remaining terms of the second polynomial to the result
    8. Display the final polynomial sum
    9. Stop

  3. Sparse Matrix Representation

    1. Start
    2. Read the number of rows and columns in the matrix
    3. Read all elements of the matrix
    4. Initialize sparse[0][0] = row, sparse[0][1] = col, count = 0
    5. For each element of the matrix
      1. if (matrix[i][j] != 0) then
        1. Store row index, column index, and value in the next triplet
        2. count++
      2. endif
    6. sparse[0][2] = count
    7. Display the triplet representation
    8. Stop

  4. Sparse Matrix Addition

    1. Start
    2. Read the size of both sparse matrices
    3. Read the number of non-zero elements in each matrix
    4. Read both matrices in triplet form (row, col, value)
    5. Initialize pointers i, j, and k to the first non-zero entries of both matrices and the result
    6. while (i <= n1 and j <= n2)
      1. if (row1[i] == row2[j] and col1[i] == col2[j]) then
        1. sum[k] = (row, col, value1 + value2)
        2. i++, j++, k++
      2. else if (row1[i] < row2[j] or row1[i] == row2[j] and col1[i] < col2[j]) then
        1. sum[k] = A[i]
        2. i++, k++
      3. else
        1. sum[k] = B[j]
        2. j++, k++
      4. endif
    7. Copy remaining elements from the first matrix to the result
    8. Copy remaining elements from the second matrix to the result
    9. Set the result count and display the triplet matrix
    10. Stop

  5. Transpose of Sparse Matrix

    1. Start
    2. Read the number of rows, columns, and non-zero elements
    3. Read the sparse matrix in triplet form (row, col, value)
    4. For each triplet
      1. transpose[i][0] = sparse[i][1]
      2. transpose[i][1] = sparse[i][0]
      3. transpose[i][2] = sparse[i][2]
    5. Sort the transposed triplets by row and then by column
    6. Display the transposed sparse matrix
    7. Stop

  6. Stack Using an Array

    1. Start
    2. Initialize top = -1
    3. Repeat until user chooses to exit
      1. Display menu: Push, Pop, Display, Exit
      2. Read choice
      3. Perform the selected operation
    4. Push
      1. if (top == MAX-1) then
        1. print "Stack Overflow"
        2. exit
      2. endif
      3. top = top + 1
      4. stack[top] = value
    5. Pop
      1. if (top == -1) then
        1. print "Stack Underflow"
        2. exit
      2. endif
      3. value = stack[top]
      4. top = top - 1
      5. Display removed value
    6. Display
      1. if (top == -1) then
        1. print "Stack Underflow"
        2. exit
      2. endif
      3. for (i = top to 0)
        1. print stack[i]
    7. Stop

  7. Queue Using an Array

    1. Start
    2. Initialize front = -1 and rear = -1
    3. Repeat until user chooses to exit
      1. Display menu: Enqueue, Dequeue, Display, Exit
      2. Read choice
      3. Perform selected operation
    4. Enqueue
      1. if (rear >= MAX-1) then
        1. print "Queue Overflow"
        2. exit
      2. endif
      3. if (front == -1) then
        1. front = 0
      4. endif
      5. rear = rear + 1
      6. queue[rear] = value
    5. Dequeue
      1. if (front == -1 or front > rear) then
        1. print "Queue Underflow"
        2. exit
      2. endif
      3. value = queue[front]
      4. front = front + 1
      5. Display removed value
    6. Display
      1. if (front == -1 or front > rear) then
        1. print "Queue Underflow"
        2. exit
      2. endif
      3. for (i = front to rear)
        1. print queue[i]
    7. Stop

  8. Circular Queue Using an Array

    1. Start
    2. Initialize front = 0, rear = MAX - 1, and count = 0
    3. Repeat until user chooses to exit
      1. Display menu: Enqueue, Dequeue, Display, Exit
      2. Read choice
      3. Perform selected operation
    4. Enqueue
      1. if (count == MAX) then
        1. print "Queue Overflow"
        2. exit
      2. endif
      3. rear = (rear + 1) % MAX
      4. queue[rear] = value
      5. count = count + 1
    5. Dequeue
      1. if (count == 0) then
        1. print "Queue Underflow"
        2. exit
      2. endif
      3. value = queue[front]
      4. front = (front + 1) % MAX
      5. count = count - 1
      6. Display removed value
    6. Display
      1. if (count == 0) then
        1. print "Queue is Empty"
        2. exit
      2. endif
      3. for (i = 0 to count - 1)
        1. print queue[(front + i) % MAX]
    7. Stop

  9. Dequeue Using an Array

    1. Start
    2. Initialize front = -1 and rear = -1
    3. Repeat until user chooses to exit
      1. Display menu: Insert Front, Insert Rear, Remove Front, Remove Rear, Display, Exit
      2. Read choice
      3. Perform selected operation
    4. Insert Front
      1. if (front == 0 and rear == MAX-1) then
        1. print "Queue Overflow"
        2. exit
      2. endif
      3. if (front == -1) then
        1. front = 0, rear = 0
        2. queue[front] = value
        3. exit
      4. endif
      5. if (front > 0) then front = front - 1 and insert value
      6. else shift all elements right by one and insert at the starting position
    5. Insert Rear
      1. if (front == 0 and rear == MAX-1) then
        1. print "Queue Overflow"
        2. exit
      2. endif
      3. if (front == -1) then
        1. front = 0, rear = 0
        2. queue[rear] = value
        3. exit
      4. endif
      5. if (rear < MAX-1) then rear = rear + 1 and insert value
      6. else shift all elements left by one and insert at the end
    6. Remove Front
      1. if (front == -1 and rear == -1) then
        1. print "Queue Underflow"
        2. exit
      2. endif
      3. value = queue[front]
      4. if (front == rear) then
        1. front = rear = -1
      5. else front = front + 1
      6. endif
      7. Display removed value
    7. Remove Rear
      1. if (front == -1 and rear == -1) then
        1. print "Queue Underflow"
        2. exit
      2. endif
      3. value = queue[rear]
      4. if (front == rear) then
        1. front = rear = -1
      5. else rear = rear - 1
      6. endif
      7. Display removed value
    8. Display
      1. if (front == -1) then
        1. print "Queue is Empty"
        2. exit
      2. endif
      3. for (i = front to rear)
        1. print queue[i]
    9. Stop

  10. Infix to Postfix Conversion

    1. Start
    2. Read the infix expression
    3. Initialize an empty operator stack
    4. Scan the expression from left to right
      1. if the character is an operand then
        1. print it immediately
      2. else if the character is ( then
        1. push it onto the stack
      3. else if the character is ) then
        1. pop and print operators until ( is reached
      4. else if the character is an operator then
        1. while the stack top has an operator of higher or equal precedence, pop and print it
        2. push the current operator
      5. endif
    5. After scanning the whole expression, pop and print all remaining operators from the stack
    6. Stop

  11. Postfix Evaluation

    1. Start
    2. Read the postfix expression
    3. Initialize an empty operand stack
    4. Scan the expression from left to right
      1. if the token is a number then
        1. push it into the stack
      2. else if the token is an operator then
        1. pop the top two values as val1 and val2
        2. apply the operation val1 operator val2
        3. push the result back onto the stack
      3. endif
    5. When the expression ends, the top of the stack contains the final result
    6. Display the result
    7. Stop

  16. Linear Search

    1. Start
    2. Read the array and the target value
    3. For each index i from 0 to n-1
      1. if (array[i] == target) then
        1. print the index where it was found
        2. exit
      2. endif
    4. If no match is found, print "Number not found"
    5. Stop

  17. Binary Search

    1. Start
    2. Read the sorted array and the target value
    3. Set left = 0 and right = n-1
    4. while (left <= right)
      1. mid = (left + right) / 2
      2. if (array[mid] == target) then
        1. print the position of the target
        2. exit
      3. else if (array[mid] < target) then
        1. left = mid + 1
      4. else
        1. right = mid - 1
      5. endif
    5. If the loop ends without finding the value, print "Number not found"
    6. Stop

  18. Insertion Sort

    1. Start
    2. Read the array elements
    3. for (i = 1 to n-1)
      1. key = array[i]
      2. j = i - 1
      3. while (j >= 0 and array[j] > key)
        1. array[j+1] = array[j]
        2. j--
      4. array[j+1] = key
      5. Display the array after each pass
    4. Display the sorted array
    5. Stop

  19. Selection Sort

    1. Start
    2. Read the array elements
    3. for (i = 0 to n-2)
      1. smallest = i
      2. for (j = i + 1 to n-1)
        1. if (array[j] < array[smallest]) then
          1. smallest = j
        2. endif
      3. Swap array[i] and array[smallest]
      4. Display the array after each pass
    4. Display the final sorted array
    5. Stop

  20. Quick Sort

    1. Start
    2. Read the array elements
    3. Call quickSort(low, high)
      1. if (low < high) then
        1. Choose the last element as pivot
        2. Partition the array so that elements smaller than the pivot are placed on the left and larger elements on the right
        3. pivotIndex = correct position of pivot
        4. Recursively sort the left part low ... pivotIndex - 1
        5. Recursively sort the right part pivotIndex + 1 ... high
      2. endif
    4. Display the sorted array
    5. Stop

  21. Merge Sort

    1. Start
    2. Read the array elements
    3. Call mergeSort(array, left, right)
      1. if (left < right) then
        1. mid = (left + right) / 2
        2. Recursively sort the left half
        3. Recursively sort the right half
        4. Merge the two sorted halves by comparing values
      2. endif
    4. Display the final sorted array
    5. Stop
